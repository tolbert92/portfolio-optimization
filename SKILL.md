# Portfolio Optimization

## Purpose

The Portfolio Optimization skill evaluates investment allocations using Modern Portfolio Theory (MPT) and mean-variance optimization.

It combines two inputs:

1. An investor profile generated by the Individual Investment Profile Builder.
2. Validated financial market statistics generated by the Market Data Analyst.

The skill generates portfolio allocations that balance expected returns against investment risk while respecting investor-specific constraints.

This skill is designed as a component of an AI Portfolio Optimization Agent.

## When to Use

Use this skill when the user wants to:

- Optimize an investment portfolio.
- Evaluate asset allocation strategies.
- Balance expected returns and investment risk.
- Compare portfolio alternatives.
- Generate an efficient frontier.
- Assess portfolio diversification.
- Evaluate investment constraints.
- Analyze portfolio sensitivity to market assumptions.
- Prepare optimization inputs and outputs for another AI agent.

## Required Inputs

### 1. Investor Profile

Obtain the following information:

- Investment objective
- Investment time horizon
- Initial investment amount
- Planned contributions
- Risk tolerance
- Liquidity requirements
- Permitted asset classes
- Investment restrictions
- Minimum and maximum allocation constraints, if specified

Use the approved output of the Individual Investment Profile Builder when available.

Do not invent missing investor requirements.

### 2. Market Data

Obtain validated statistics from the Market Data Analyst:

- Asset identifiers
- Expected annualized returns
- Annualized volatility
- Covariance matrix
- Correlation matrix
- Historical observation period
- Data source
- Validation status
- Data quality exceptions

Only use market statistics that have passed the applicable validation requirements.

Synthetic market data may be used for demonstrations, but must be clearly identified as simulated.

## Operating Principles

1. Never invent actual market prices, returns, or investment performance.
2. Never represent simulated results as actual historical performance.
3. Do not optimize using unvalidated or incomplete required inputs.
4. Apply investor restrictions before generating allocations.
5. Use a fully invested portfolio unless explicitly instructed otherwise.
6. Do not allow short selling or leverage unless specifically authorized.
7. Explain the assumptions used in the optimization.
8. Distinguish expected returns from guaranteed returns.
9. Document model limitations and sensitivity to assumptions.
10. Treat portfolio recommendations as analytical decision support, not personalized financial advice.

# Five-Phase Workflow

## Phase 1 — INGEST

### Objective

Collect and verify the investor profile and market statistics.

### Actions

1. Read the investor profile.
2. Identify eligible investment assets.
3. Read validated market statistics.
4. Verify that all required asset identifiers match.
5. Confirm that expected returns and covariance use consistent annualized units.
6. Verify that the covariance matrix is symmetric and positive semidefinite within numerical tolerance.
7. Confirm that all required values are finite and that covariance diagonal entries are nonnegative.
8. Identify missing inputs, inconsistencies, and restrictions.

### Required Output

An input validation summary identifying:

- Investor objectives
- Eligible assets
- Risk classification
- Available market statistics
- Constraints
- Validation status
- Unresolved issues

Do not proceed if critical validation requirements fail.

## Phase 2 — CONFIGURE

### Objective

Translate the investor profile into an optimization problem.

### Default Optimization Method

Mean-Variance Optimization.

### Primary Objective

Balance expected portfolio return and portfolio variance.

Use the objective:

Maximize:

Expected Portfolio Return - (Risk Aversion / 2) × Portfolio Variance

Where:

- Expected Portfolio Return = wᵀμ
- Portfolio Variance = wᵀΣw
- w = portfolio weight vector
- μ = expected annualized return vector
- Σ = annualized covariance matrix

### Risk Aversion

Use a configurable investor-adaptive risk-aversion parameter.

For educational testing, the following are provisional defaults:

| Investor Risk Profile | Risk-Aversion Parameter |
|---|---:|
| Conservative | 8 |
| Moderate | 4 |
| Aggressive | 2 |

These parameters are illustrative and are not empirically calibrated.

Allow the user to review and override them.

### Default Investment Constraints

- All portfolio weights must be nonnegative.
- Portfolio weights must total 100%.
- No leverage.
- No short selling.
- Use only approved assets.
- Apply investor-specified allocation limits.
- Apply liquidity restrictions when mathematically defined and supported.

Do not interpret a preferred maximum drawdown as a guaranteed loss limit or automatically equate it with a volatility constraint.

### Required Output

An optimization configuration containing:

- Objective function
- Risk-aversion parameter
- Eligible assets
- Weight constraints
- Investor restrictions
- Model assumptions

## Phase 3 — OPTIMIZE

### Objective

Calculate the optimal portfolio allocation.

### Actions

1. Construct the expected-return vector.
2. Construct the annualized covariance matrix.
3. Apply portfolio constraints.
4. Solve the mean-variance optimization problem using a suitable numerical optimization method.
5. Verify numerical convergence and feasibility.
6. Calculate portfolio expected return.
7. Calculate portfolio variance and volatility.
8. Generate efficient-frontier portfolios across feasible target returns.
9. Verify that each reported allocation satisfies all constraints.

### Portfolio Calculations

Expected Portfolio Return:

Rₚ = Σ(wᵢ × μᵢ)

Portfolio Variance:

σₚ² = wᵀΣw

Portfolio Volatility:

σₚ = √(wᵀΣw)

### Efficient Frontier

Generate a series of feasible portfolios that minimize variance for different target expected returns.

Identify the selected investor-adaptive portfolio on the frontier.

Do not claim an optimization succeeded unless a numerical solution was actually calculated and verified.

If a numerical solver is unavailable, report the limitation. Do not fabricate optimized weights or an efficient frontier.

### Required Output

- Optimal portfolio weights
- Expected annualized return
- Expected annualized volatility
- Portfolio variance
- Efficient-frontier results
- Optimization status
- Constraint validation

## Phase 4 — ANALYZE

### Objective

Interpret the optimization results and evaluate their robustness.

### Required Analysis

#### Asset Allocation

Explain the percentage allocated to each asset and its role in the portfolio.

#### Risk and Return

Explain the expected portfolio return and volatility.

Clarify that volatility is not equivalent to maximum drawdown.

#### Diversification

Evaluate how asset correlations and covariance influence portfolio risk.

#### Investor Alignment

Assess whether the allocation is consistent with the investor's objectives, risk tolerance, and restrictions.

#### Sensitivity Analysis

Where feasible, evaluate how allocations change when:

- Expected returns increase or decrease.
- Volatility assumptions change.
- Correlations change.
- Risk-aversion parameters change.
- Allocation constraints change.

#### Limitations

Document:

- Dependence on estimated expected returns
- Historical-data limitations
- Sensitivity to model assumptions
- Potential estimation error
- Transaction costs and taxes not modeled unless supplied
- Absence of guarantees regarding future performance

### Required Output

A clear explanation of the allocation, risk-return trade-offs, diversification, sensitivity, and model limitations.
